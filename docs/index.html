AgentForge turns one .agentforge.yaml into native rule files for Cursor, Claude Code, Windsurf, Antigravity, Copilot, Aider and Cline, packs your code into token-light AST skeletons, lints your rules for leaked keys and dangerous directives, and ships 7 built-in skills.ایجنت‌فورج یک فایل ‎.agentforge.yaml را به فایل‌های قانون بومیِ Cursor، Claude Code، Windsurf، Antigravity، Copilot، Aider و Cline تبدیل می‌کند، کدتان را به اسکلت‌های AST کم‌توکن فشرده می‌کند، قوانین را برای کلیدهای لورفته و دستورهای خطرناک بررسی می‌کند و ۷ مهارت آماده دارد.

agentforge packagentforge pack

Hammer code into skeletons.کد را به اسکلت تبدیل کنید.

The Token-Killer keeps what an agent needs to reason about your code (exports, signatures, types, docstrings) and strips routine bodies. The result is one Markdown context bundle.«توکن‌کُش» چیزهایی را که ایجنت برای فهم کد لازم دارد (خروجی‌ها، امضاها، تایپ‌ها و توضیحات) نگه می‌دارد و بدنهٔ توابع را حذف می‌کند. خروجی یک بستهٔ کانتکست مارک‌داون است.

src/cart.tsoriginalاصلی · ~233 tok
export interface Item { id: string; price: number; qty: number }
/** Sum the cart total in rials */
export function total(items: Item[]): number {
  let t = 0;
  for (const i of items) { t += i.price * i.qty; }
  return Math.round(t);
}
export class Cart {
  private items: Item[] = [];
  add(item: Item): void { this.items.push(item); console.log('added', item.id); }
  clear(): void { this.items = []; }
}

Quick startشروع سریع

Light the forge in 30 seconds.در ۳۰ ثانیه کوره را روشن کنید.

# in your project (Node 18+, npm 10+ recommended)
npx github:mrzroot/agentforge init       # detects your stack
npx github:mrzroot/agentforge sync       # write every agent's rules
npx github:mrzroot/agentforge pack --out CONTEXT.md
npx github:mrzroot/agentforge lint
npx github:mrzroot/agentforge ui         # http://localhost:3737
git clone https://github.com/mrzroot/agentforge.git
cd agentforge
npm install      # builds via the prepare script
npm link         # puts `agentforge` and `af` on your PATH

cd ~/your-project
agentforge init -y
agentforge sync --targets cursor claude aider
Heads-up: AgentForge isn't published on npm yet, so npx agentforge won't work. Use the github: form or a source checkout.توجه: ایجنت‌فورج هنوز در npm منتشر نشده، پس npx agentforge کار نمی‌کند. از شکل github: یا نسخهٔ سورس استفاده کنید.

FAQپرسش‌های رایج

Questions from the anvil.پرسش‌ها از کنار سندان.

Is it on npm?در npm هست؟

Not yet. Run it with npx github:mrzroot/agentforge <command>, which installs from the repo and builds automatically, or clone it and npm link.هنوز نه. با npx github:mrzroot/agentforge <command> اجرایش کنید که از مخزن نصب و خودکار ساخته می‌شود، یا مخزن را کلون و npm link کنید.

Does my code leave my machine?کد من از سیستمم خارج می‌شود؟

No. Sync, pack and lint are plain local file operations, and the Web Studio is served from your own machine. AgentForge has no telemetry and makes no API calls.نه. sync، pack و lint عملیات ساده روی فایل‌های محلی‌اند و استودیوی وب هم از خود سیستم شما سرو می‌شود. ایجنت‌فورج تله‌متری ندارد و هیچ API ای را صدا نمی‌زند.

Will sync overwrite my hand-written CLAUDE.md?sync فایل CLAUDE.mdِ دست‌نویس من را بازنویسی می‌کند؟

Yes, generated files are owned by AgentForge: changed ones are reported as updated, identical ones as unchanged. Move your existing guidance into .agentforge.yaml first, commit, and use --dry-run to preview.بله، فایل‌های تولیدی متعلق به ایجنت‌فورج‌اند: فایل‌های تغییرکرده updated و فایل‌های یکسان unchanged گزارش می‌شوند. اول راهنمایی‌های فعلی را به ‎.agentforge.yaml منتقل و کامیت کنید و با --dry-run پیش‌نمایش بگیرید.

How accurate are the token numbers?اعداد توکن چقدر دقیق‌اند؟

They come from a fast BPE-style heuristic, close enough to compare before and after, but not your model's exact tokenizer. Savings depend on how much of your code is function bodies.از یک تخمین سریع شبیه BPE می‌آیند؛ برای مقایسهٔ قبل و بعد کافی‌اند، اما توکنایزر دقیق مدل شما نیستند. میزان صرفه‌جویی به سهم بدنهٔ توابع در کدتان بستگی دارد.

Which languages can pack skeletonize?pack کدام زبان‌ها را اسکلت می‌کند؟

TypeScript and JavaScript (including JSX/TSX), Python, Go, Rust and PHP. JSON is condensed; other files are included as text. Include and exclude globs and a per-file token cap live under compression: in the YAML.TypeScript و JavaScript (با JSX/TSX)، Python، Go، Rust و PHP. JSON فشرده می‌شود و بقیهٔ فایل‌ها متنی می‌آیند. الگوهای include/exclude و سقف توکن هر فایل زیر compression: در YAML تنظیم می‌شوند.

Can I add my own agent target or skill?می‌توانم ایجنت یا مهارت خودم را اضافه کنم؟

Yes. Targets are small generators in src/core/sync and skills sit in src/core/skills/registry.ts. PRs are welcome.بله. مقصدها مولدهای کوچکی در src/core/sync هستند و مهارت‌ها در src/core/skills/registry.ts. PR شما خوش‌آمد است.
